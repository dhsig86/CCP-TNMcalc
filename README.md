CCP-TNMcalc
CCP-TNMcalc é uma aplicação web desenvolvida para calcular o estadiamento TNM do câncer cervical baseado nos critérios mais recentes. Este projeto visa facilitar a avaliação do estágio do câncer cervical de forma precisa e rápida.

Funcionalidades
Cálculo do Estadiamento TNM: Insira os dados clínicos do paciente para calcular automaticamente o estadiamento TNM do câncer cervical.
Interface Intuitiva: Interface amigável e fácil de usar para profissionais de saúde.
Resultados Imediatos: Exibe os resultados do estadiamento imediatamente após a entrada dos dados.
Tecnologias Utilizadas
Frontend: HTML, CSS, JavaScript
Hospedagem: GitHub Pages
